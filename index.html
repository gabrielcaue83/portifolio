        ease: "?"
        
O ritmo do movimento

        
Toda animação acelera e freia de algum jeito. A curva de easing é o que separa um movimento robótico de um que tem personalidade. Escolhe uma:

        

          
          
          
          
          
          
        

        
gsap.to(box, { x: 400, ease: "elastic.out(1, 0.3)" })

        stagger: { grid, from }
        
Um clique, cem animações

        
Cada bolinha começa um pouquinho depois da vizinha, de acordo com a distância até onde você clicou. Clica em qualquer uma.

        
gsap.to(dots, { scale: 0.2, stagger: { each: 0.04, grid: "auto", from: i } })

      

      

        

        from: "center"

        Flip.from(state)
        
Layout que se arruma sozinho

        
O Flip grava onde cada bloco estava, troca o layout e anima a diferença. Muda o layout aqui embaixo ou clica num bloco pra ele crescer.

        

          
          
          
          
        

        
const state = Flip.getState(tiles); mudaLayout(); Flip.from(state)
